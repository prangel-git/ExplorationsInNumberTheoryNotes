A **primitive root** is an element $g \in \mathbb{Z}/(p)^{\times}$ if the order of $g$ equals $p-1$. In other words, a primitive root is an element that generates the whole multiplicative group of $\mathbb{Z}/(p)^{\times}$

## Theorem

For every natural number $n$, we have

$$
\sum_{d \mid n} phi(d) = n
$$

## Primitive root theorem

Let $p$ be prime. For a divisor $d$ of $p-1$, the number of elements of order $d$ in $\mathbb{Z}/(p)^{\times}$ is $\phi(d)$. In particular, there are $\phi(p-1)$ primitive roots modulo each prime $p$.
